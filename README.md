# Sou9 DZ

Application Android de vente et achat, première version UI.

## Fonctionnalités de la V1
- Accueil
- Recherche
- Catégories
- Annonces
- Favoris (interface)
- Publication d'annonce (interface)
- Compte (interface)

## Prochaine étape
Ajouter une base de données, authentification, stockage des photos, chat vendeur/acheteur,
géolocalisation, notifications et modération.
